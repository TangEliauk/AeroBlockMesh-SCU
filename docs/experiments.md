# 二维 SAC 实验与记录约定

## 已有二维原型实验

采用解析生成的闭合尾缘 NACA 四位数翼型，固定四块共形 O 型拓扑。144 个训练、16 个验证和 24 个测试翼型使用固定划分。20 个有弯度测试翼型的弯度与最大弯度位置组合在训练时整体留出。调参示范来自训练翼型上的搜索，检查点按验证集评分选择。

标准分辨率为每例 1,536 个四边形单元，加密分辨率为 5,120 个单元。SAC 与行为克隆使用五个训练种子（1729、1730、1731、1732、1733），复用同一组 24 个留出翼型。每次评估包括初始网格。综合分是几何指标，包含缩放雅可比、偏斜度、长宽比和无效单元惩罚。加密评价使用标准分辨率选出的参数。

| 方法 | 每例评估次数 | 标准网格平均分 ↑ | 加密网格平均分 ↑ | 标准网格有效率 |
| --- | ---: | ---: | ---: | ---: |
| 固定参数 | 1 | 0.739398 | 0.753803 | 23/24 |
| 训练集全局调参 | 1 | 0.776562 | 0.793517 | 24/24 |
| 一步岭回归 | 1 | 0.776240 | 0.793013 | 24/24 |
| 全局起点＋局部搜索 | 9 | 0.777008 | 0.793473 | 24/24 |
| 行为克隆 | 9 | 0.776534 | 0.793126 | 120/120 |
| SAC | 9 | 0.776781 | 0.793262 | 120/120 |

在相同 9 次网格评估预算下，SAC 比行为克隆高 0.000248，比全局起点加局部搜索低 0.000227。SAC 的五个种子均值标准差为 0.000273。局部搜索在五个配对种子中的四个得分更高。加密网格上，训练集全局调参均分最高。当前结果支持二维固定拓扑自动调参的可行性。对一般性的 SAC 优越性仍缺少证据。

这个实验的分析范围是解析 NACA 网格几何质量。SAC 标准网格平均首层厚度为 0.01961 倍弦长，固定参数为 0.01031 倍弦长。求解误差和边界层分辨率需要单独的 CFD 工况验证。

本实验独立于 UIUC v1。解析训练翼型 0008、0015、0021、1410 的名称也出现在 UIUC v1 的冻结测试组中。两个来源的坐标生成方式不同。若将来使用 UIUC 最终测试集，需要重新处理这种跨基准家族重叠。

## 随包检查点和复现

内置 SAC 检查点来自上述实验的种子 1729，训练预算 24,000 步，在第 19,200 步由验证集选出。该检查点标准分辨率留出均分为 0.777035，与表中五种子均值的统计口径不同。

```powershell
python scripts/evaluate.py --naca-2d
python scripts/train_rl.py --naca-2d --steps 24000 --seed 1729
```

评估入口用于检查内置或指定检查点。表中的五种子比较来自原型的既有实验记录，每个种子的测试对象一致。内置检查点在 `src/smartcfd/rl/agents/data/naca_2d_sac_actor.npz`。SHA-256 为 `a70a6b2cf6456542624ce6a79325adc00c5e8250de062f6ea7e2c9d2f474168a`。

完整对照可以用五组训练输出重算。在同一目录中已存在某个种子的训练记录时，可以直接复用。汇总默认写入新的 `experiments/results/naca-2d-evidence/`，包含逐翼型 CSV、指标 JSON 和供演示页使用的数据。

```powershell
1729..1733 | ForEach-Object {
    python scripts/train_rl.py --naca-2d --steps 24000 --seed $_
}
python experiments/sac_2d/compare.py
```

## 后续实验记录

每次运行应分配独立标识，并记录：代码提交版本、未提交改动说明、完整配置快照、数据版本与划分、随机种子、软件与求解器版本、硬件信息以及起止时间。输出路径不得覆盖已有运行。

| 目录 | 计划内容 |
| --- | --- |
| `experiments/checkpoints/` | 训练检查点及其对应的运行和配置标识 |
| `experiments/logs/` | 训练、网格生成、质量检查及求解器日志 |
| `experiments/results/` | 评价摘要、导出网格、图表和 CFD 验证结果 |

这些目录中的生成内容默认不进入 Git。可供审查的实验说明可单独写入文档，并注明原始结果位置；不得只保留最优样本而丢弃失败记录。

比较规则分块、模板分块与学习方法时，应使用同一数据划分、几何约束、网格规模预算和评价定义。记录每个几何的有效性、质量分布、失败率与运行时间；训练方法还需记录多随机种子运行与模型选择依据。

开展 CFD 验证时，另外记录边界条件、物性、求解器设置、残差定义、收敛判据、网格规模和参考结果来源。网格质量改善与物理量误差改善应分别报告，尚未收敛的运行不得计作成功。

任何结果表都应能追溯至具体输入与运行记录。实验设计、统计汇总和通过标准需要在实现对应功能时进一步明确。
