## 图注及逐图证据

### 图 01 FusionSAC 总体研究框架

FusionSAC 对翼型坐标归一化，构建 C 型域与固定近壁保护带。策略结合 18 维几何特征与半边拓扑状态，从合法候选中选择离散动作。经核验的教师示范用于行为克隆，在线 SAC 使用经验回放和双 Critic。STOP 确认的四边化终态用于两档 TFI 网格与 SU2 验证，低分辨率 TFI 提供独立的终局质量反馈。

### 图 02 翼型预处理与初始计算域

以冻结留出翼型 n5h20 为例，将原始坐标去重并整成单位弦轮廓。C 型外域沿尾迹接缝展开成 UV 域，v=0.5 将固定的四个近壁保护块与待分解十边形隔开。A–C 对照物理和 UV 中的同名节点。

### 图 05 FusionSAC 离散候选网络

Actor 和各 Critic 各自编码输入，并为每个候选输出一个标量。两层半边消息利用 next、previous 与 twin，半边均值、最大值及全局投影构成 192 维上下文。几何分支包含厚度、弯度、位置与尾缘量。E4a 关闭几何分支，E4 采用 FIFO 候选策略。Actor 在合法候选上计算分类分布，双目标 Critic 由在线 Critic 软更新。

### 图 06 BC 预训练与离散 SAC 训练

训练集教师筛出 124 条合法示范，覆盖 496 个动作。E5 完成 1,000 次 BC 更新；E7/E8 载入同种子 E5 final Actor，并在示范回放上预热 Critic 128 次。E6 冷启动并执行合法随机预热；E8 附加保守筛选。E6–E8 合法动作数大于 1 时可更新温度。best 仅由开发集选择。
