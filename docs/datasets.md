# 数据集约定

仓库已附带公开数据 v1：`data/processed/uiuc_v1/` 的规范化翼型几何、`data/splits/uiuc_v1/` 的固定家族分组划分，以及 `data/references/public_v1/` 的实验参照表和参考资产清单。范围、统计、数据格式与复现步骤以 [public_data_v1.md](public_data_v1.md) 和 [data/README_cleaned.md](../data/README_cleaned.md) 为准。目录职责见 [data/README.md](../data/README.md)。

`data/references/multiblock_v1/` 另外保存四组终态分块参考的 5 个原件，`data/processed/block_topology_v1/` 保存实际解析清洗的 JSON。清洗保留源坐标与单位，只提取已知结构并验证尺寸、引用和接口；ICEM 未确认的活动块语义等限制保留在产物中。原 `public_v1` 是冻结快照，不为新增发布改写历史哈希；新增实体和派生文件以 [multiblock_v1 清单](../data/references/multiblock_v1/manifest.json) 为准。

`scripts/data/` 已实现公开数据下载、清洗、划分和核验，`tests/data/` 提供回归测试；这部分不是算法占位文件。多块 HDF5 清洗需要可选的 NumPy/h5py 依赖。数据处理可独立使用，但 `src/smartcfd` 的自动分块、强化学习、网格生成与 CFD 验证仍待实现。几何、实验参照和分块终态都没有对应的专家逐步动作或 SAC 经验回放。

每个数据来源应记录名称、来源链接或存放位置、获取日期、版本、使用许可、单位、坐标系以及预处理步骤。原始数据保留不改，处理结果应能追溯到原文件及处理参数。未经许可的数据不应提交至仓库。

训练、验证和测试划分使用稳定的几何标识，并在 `data/splits/` 中版本管理轻量清单。现有 `uiuc_v1` 已按家族与检测到的近重复建立连通组，NACA 连通家族留作最终测试；筛查规则及局限见 [数据说明](public_data_v1.md)。新增数据时，同一几何的重采样、尺度变化或其他派生样本应归入同一划分，并记录家族分组策略以避免数据泄漏。

四组终态参考独立于现有 UIUC 划分，暂不指定为训练样本；M6 继续作为工程/CFD 参考。ICEM 粗、中、细是同一几何，不能拆成三个独立几何放入不同子集。终态推导的动作序列若将来加入，需单独标为重建并在环境内逐步重放验证。

训练集用于拟合；验证集用于超参数、奖励权重和检查点选择；测试集仅用于最终评价。归一化和其他需要拟合的预处理参数只从训练集估计，再应用于其余集合。

专家示范应记录几何标识、操作顺序、分块结果、约束条件和标注来源。其有效性检查、字段格式和读取方式待实现，不假定 `data/expert/` 中已存在可用训练样本。

公开数据 v1 的几何、实验表、划分和来源清单已纳入版本管理。`.gitkeep` 仅用于跟踪其他空目录；大体积原始数据、模型参数和后续生成结果默认留在本地或外部存储，清单应记录校验值或版本标识。复现时优先输出到独立目录，再与冻结的 v1 比较，避免覆盖原版本。

实验参照的不同工况必须分别保留，数据质量检查不能替代 CFD 数值验证。第三方来源、原实验归属和许可状态以 [THIRD_PARTY_DATA.md](../THIRD_PARTY_DATA.md) 为准，UIUC 数据不套用项目代码许可。
