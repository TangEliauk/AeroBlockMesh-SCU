# 七组多块分块参考的用途

这七组资料提供已完成的网格或 blocking 工程，供查看分块布局、块间对接和边界定义。
四组既有参考仍保存在 [multiblock_v1](../data/references/multiblock_v1/README.md)；新增三组二维辅助案例独立保存在 [multiblock_2d_v1](../data/references/multiblock_2d_v1/README.md)。
[机器可读用途表](../data/references/multiblock_case_catalog.json)记录每组的参考信息、用途、定位、维度和限制；这些定位是本项目的研究判断。

## 各组适合参考什么

| 数据 | 维度及可参考的终态信息 | 用途与课题定位 |
| --- | --- | --- |
| CGNS 十二块收缩通道 | 三维；已解析 12 区、20 组去重一对一接口及边界分类 | 测试结构块、连接与数据结构；不是二维翼型训练主线 |
| CGNS 四块多段翼型 | 二维问题，以第三方向两层点平面保存；已解析 4 区、8 组去重接口及边界 | 七组中最贴近二维翼型外流分块主线；原件的两平面保留 |
| DLR-F6 ICEM 工程 | 三维翼身；TIN 几何与粗、中、细三份 BLK 源记录 | 参考工程 blocking 定义与密度设置，服务后续三维阶段；活动流体块集合尚未可靠解释 |
| ONERA M6 四块网格与 GMAN | 三维机翼；已解析 4 块、24 个面声明及 6 组坐标核验接口 | 后续机翼块面连接与 CFD 验证准备；不是二维样本 |
| TMR 四块后向台阶 `backstep4` | 真正二维 PLOT3D，选最粗一级；配套 NMF 原为两平面三维版本 | 非凸流域、角点和一对一对接的基础辅助基准；可作课程学习候选 |
| CFL3D 三块喷射器 `ejector3` | 二维内流问题，以两平面 PLOT3D 保存；附网格与求解输入 | 参考流道汇合处的点匹配、子边对接；作为可选跨构型测试 |
| CFL3D 四块带腔 Hump `hump4` | 二维问题，以两平面 PLOT3D 保存；含控制缝、腔体及配套输入 | 复杂二维曲壁和局部接口的辅助验证；不能替代翼型或机翼主体样本 |

前四组的实际解析范围见 [既有清洗产物说明](../data/processed/block_topology_v1/README.md)，新增三组见 [二维清洗产物说明](../data/processed/block_topology_2d_v1/README.md)。
接口数采用各产物明确记录的去重口径，不等同于不同块对的数量，也不能用来直接比较分块优劣。
ICEM 每份 BLK 的 **374 条 `SUPERBLOCKS` 是源记录数，不是已确认的 374 个活动流体块**。

## 新增三组的读取边界

新增原件共 11 个文件、31,757,575 字节，逐字节保留官方文件或归档成员；来源、归档哈希和文件哈希见 [独立清单](../data/references/multiblock_2d_v1/manifest.json)。
其中 Hump 网格展开后为 30,668,830 字节；官方下载归档约 3.61 MB，不能把压缩下载量当成入库文件总量。
原坐标不平滑、不重采样、不归一化；原始完整坐标留在参考目录，派生 JSON 单独记录二维表达。

后台阶网格本身是二维，其 NMF 使用薄层三维的面编号与索引。
使用配套声明时需要明确投影到二维边，不能把 NMF 索引直接套到二维数组，或把投影后的声明自动当作已验证连接；本清洗器不自动解析 NMF 或 CFL3D 输入的全部语义。
喷射器和 Hump 从薄层文件选择二维平面前，需检查两平面的面内坐标一致；选择的坐标轴、平面与最大差值以派生 JSON 为准。
清洗按原坐标寻找连续子边匹配，保留局部边、反向索引及源范围；这些接口是坐标核验得到的候选，不冒充求解输入中显式给出的索引变换。
本次提取后台阶 4 块/3 组、喷射器 3 块/2 组、Hump 4 块/3 组接口候选，逐点最大坐标差均为 0；三组分别还有 11、10、12 段未自动分类的边界。

块边界折线和接口映射可作为终态分块参考；它们不证明块内部互不重叠，也不代表单元 Jacobian、边界条件完备性或 CFD 精度已经合格。
配套求解输入只作为来源材料，项目没有因此执行 CFL3D、GMAN 或其他 CFD 求解器，也不声称已接通强化学习环境。

## 复现与核对

在仓库根目录执行；已提交原件可离线清洗，不必重新下载：

```shell
python scripts/data/clean_2d_multiblock.py --check
python scripts/data/verify_2d_multiblock_data.py
```

需要重新生成时运行不带 `--check` 的清洗器。更新派生文件后须审查差异，再同步独立清单中的哈希；不要以改哈希掩盖源文件变化。
下载器按原始资产 ID 显式选择文件，先列出所有可选项：

```shell
python scripts/data/download_2d_reference_sources.py --list
python scripts/data/download_2d_reference_sources.py --ids backstep4_grid backstep4_nmf --output-root data/raw/2d_source_rebuilt
```

`--output-root` 指替代仓库根目录，会在其下保留 `data/references/multiblock_2d_v1/...` 的完整相对路径。
下载器检查固定字节数和哈希；已有匹配文件复用，冲突文件不会被静默覆盖。后台阶从有界 ZIP 成员获取，CFL3D 案例按归档成员提取。

## 科研使用边界

七组都没有原始专家逐步动作；成品网格和 ICEM 终态工程不能直接作为行为克隆的状态—动作对或 SAC 回放。
后续若从终态重建轨迹，应另标“重建/合成”，在明确定义动作和约束的环境中逐步重放，并记录人工审阅。
新增三组定位为辅助参考，不纳入冻结 UIUC 划分，不用于宣称翼型泛化、训练效果或优于人工的效率结论。

同一外形的格式转换、密度级别和重采样不算独立几何：DLR-F6 三份 BLK 属于同一外形，后台阶官方五级网格属于同一系列，本次只收最粗一级。
CFL3D Hump 与 TMR CFDVAL2004 的带腔 Hump 属于同一案例来源系列，不能换名重复计样；无腔 Hump 的单块版本也不能混作四块参考。
最终三维机翼目标仍需三维几何、块面操作和对应验证，不能由二维薄层文件替代。

来源与许可说明见 [THIRD_PARTY_DATA.md](../THIRD_PARTY_DATA.md)：TMR 仓库的 CC0 来源声明与 CFL3D 软件许可分别记录，不把软件许可自动套用到所有样例数据。
