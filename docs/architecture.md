# 项目架构

仓库名称为 `AeroBlockMesh-SCU`，Python 包名为 `smartcfd`。当前可运行的流程覆盖二维解析 NACA 翼型、固定四块 O 型拓扑、网格几何评价、SAC 调参和 PLOT3D 导出。

| 模块 | 计划职责 | 主要产物 |
| --- | --- | --- |
| `core` | 统一数据结构、标识与读写契约 | 几何、分块、网格和结果的数据定义 |
| `geometry` | 翼型及二维、三维几何处理，计算域构造和预处理 | 经检查的几何与边界标签 |
| `partition` | 块结构、拓扑、动作、约束检查和状态转移 | 合法分块及其邻接关系 |
| `rl` | 环境封装、观测与奖励，策略学习和模仿学习 | 策略参数与训练记录 |
| `meshing` | 块内结构化网格生成、映射和块间连接 | 网格坐标与接口连接关系 |
| `evaluation` | 分块与网格质量、Jacobian、正交性和边界层评价 | 定义明确的质量报告 |
| `cfd` | 外部求解器适配、边界条件、收敛检查和数值验证 | 求解记录及验证报告 |
| `baselines` | 规则分块、模板分块和传统网格方法的对照入口 | 使用相同接口的基线结果 |
| `pipeline` | 编排上述环节并保存配置、输入标识和输出 | 可追溯的运行记录 |

`core` 是上述八个业务模块共用的基础层。计划数据流为：几何 → 分块 → 网格 → 质量评价 → CFD 验证；强化学习通过环境调用分块转移及质量评价，基线方法接入同一评价流程。

二维原型从 NACA 四位数编号解析弦长归一化的形状。网格生成器规定四块的邻接关系，SAC 通过几何质量评估逐步调整五个连续网格参数，并保留有效性优先的最佳候选。生成、训练和评估入口共享这一流程。公开 UIUC 数据处理仍由 `scripts/data/` 独立运行。

依赖方向应保持清楚：`core` 不依赖业务模块；几何处理不依赖训练器；网格评价不启动 CFD；外部求解器仅通过适配层接入。计算失败、不可行分块和未收敛结果应有明确状态，不能作为有效样本或成功结果继续传播。

通用 `configs/` 仍为设计草案，二维原型通过命令行参数配置。具体接口见 [interfaces.md](interfaces.md)，实施路线见 [methodology.md](methodology.md)。
