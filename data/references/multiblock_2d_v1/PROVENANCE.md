# 二维辅助参考的来源与归属

## 新增二维多块终态参考

TMR 后向台阶原件来自[官方网格页](https://tmbwg.github.io/turbmodels/backstep_grids.html)列出的 NASA 下载归档及配套 NMF。本次只收四块网格的最粗一级与连接文件，来源按 [TMBWG/turbmodels 的 CC0-1.0 声明](https://github.com/TMBWG/turbmodels/blob/main/LICENSE)记录；保留原实验和基准构型归属，不将密度变体计作独立几何。

喷射器与带腔 Hump 原件来自 [NASA CFL3D 官方 Test Cases](https://nasa.github.io/CFL3D/Cfl3dv6/cfl3dv6_testcases.html)公开的 `Ejectornozzle.tar.gz`、`Humpcase.tar.gz`。提交所选网格、配套输入和 Hump 原始 README，逐字节保留归档成员及原有告示；归档与成员的 SHA-256 见 [manifest.json](manifest.json)。CFL3D 软件许可不自动用于所有示例数据；当前对各样例未确认独立的统一数据许可证，按官方公开提供及原署名记录为 `NOASSERTION`，不替换为项目代码许可，也不据此判定原资产禁止再分发。

派生二维 JSON 记录原件哈希、投影和检查范围，不重新授权第三方原件，也不声称原提供方认可本项目、认证网格质量或提供了原始专家动作轨迹。各组的科研定位见 [多块参考指南](../../../docs/multiblock_reference_guide.md)。

历史公开数据的归属说明保留在 [THIRD_PARTY_DATA.md](../../../THIRD_PARTY_DATA.md)，该冻结文件不因本补充集改写。
